# Job Scraper
Project Goal:
Build a Django web app that lets users enter a job search URL (e.g. LinkedIn or Indeed), the number of listings they want, and automatically scrape and store job listings in a searchable dashboard.

Core Features
User Input: URL + number of jobs to scrape

Web Scraper: Scrapes job title, company, location, description, and source URL

Company Website Lookup: Google search to find company website

Dashboard: View, search, delete job records

Data Cleanup: Deduplication logic (based on title + company)

Export: Download CSV of scraped jobs
